# Avesis Mobile Hoşgeldin 👋

yeni bir expo uygulaması oluşturmak için: [Expo](https://expo.dev) [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Başlayalım

1. Gerekli Olan Bağımlılıklar

   ```bash
   npm install
   ```

2. Expoya Start Verelim

   ```bash
   npx expo start
   ```
